# Crypto-Market-Microstructure-Volatility-Analysis
Crypto Market Microstructure &amp; Volatility Analysis

This project analyzes the statistical behavior of the BTC/USDT cryptocurrency market using historical Binance data.

The analysis focuses on:
- return dynamics
- - volatility clustering
- market regime detection
- relationships between volatility and trading activity
The project applies time-series and statistical analysis techniques to better understand how crypto markets behave under different market conditions.

## Methods
Used
- Log return analysis
- Rolling volatility estimation
- Market regime classification
- Correlation analysis
- ADF stationarity testing
  
## Key Findings
- BTC returns exhibited fat-tailed behavior with elevated kurtosis
- Volatility clustering was observed during stressed market periods
- Trading activity increased during high-volatility regimes
- Log returns were found to be stationary based on the ADF test
